# 📡 Telegram Popup — מעקב ערוצי טלגרם ציבוריים

תוכנה שעוקבת אחרי ערוצי טלגרם ציבוריים ומציגה אותם בממשק מסנג'ר מודרני
משלך — בלי חשבון טלגרם, בלי התקנות מסובכות. במחשב היא גם מקפיצה התראות
על כל הודעה חדשה; אונליין היא דף חי שנפתח מכל מקום, גם מהטלפון.

## 🌐 גרסה אונליין — הדף החי מכל מקום

אפשר להריץ את הדף החי על שרת חינמי בענן ולפתוח אותו מכל מכשיר:

1. הירשם ל-[render.com](https://render.com) (אפשר עם חשבון הגיטהאב).
2. לחץ **New +** ← **Blueprint** ← בחר את המאגר הזה ← **Apply**.
3. המתן כ-5 דקות לבנייה. הכתובת תופיע למעלה (משהו כמו
   `https://telegram-popup-xxxx.onrender.com`).
4. **מפתח הגישה**: בלוח של Render ← השירות ← לשונית **Environment** ←
   העתק את הערך של `TGPOPUP_KEY`. בכניסה הראשונה לדף תתבקש להזין אותו —
   פעם אחת בכל מכשיר.

רשימת הערוצים אונליין נקבעת במשתנה `TGPOPUP_CHANNELS` באותה לשונית —
שנה, לחץ Save, והשירות יופעל מחדש עם הרשימה החדשה.

### בטלפון — כאפליקציה

פתח את הכתובת בטלפון, היכנס עם המפתח, ואז:
- **אנדרואיד (כרום)**: יופיע כפתור **📲 התקן כאפליקציה** בצד. לחיצה אחת
  והאייקון במסך הבית.
- **אייפון (ספארי)**: כפתור השיתוף ⎋ ← **הוסף למסך הבית**.

בתוך האפליקציה: הכפתור 🔔 בראש הדף מפעיל **התראות בדפדפן** — קופצות כשהדף
ברקע או כשאתה בערוץ אחר. ההתראות עובדות כל עוד האפליקציה פתוחה ברקע
(אין שרת דחיפה — השרת החינמי נרדם, ראה למטה).

### כדאי לדעת

- **בחינם יש הרדמה**: אחרי רבע שעה בלי מבקרים השרת נרדם, והכניסה
  הבאה לוקחת כדקה להתעורר. זה נורמלי — הדף מציג "מעיר את השרת…" ונפתח
  לבד כשהשרת עונה.
- **כניסה**: המפתח מוזן בטופס, נשמר בעוגייה מאובטחת לשנה, ולא מופיע
  בכתובת. אחרי שש טעויות ברצף יש המתנה של שתי דקות.
- **שעות**: מוצגות לפי השעון של המכשיר שממנו צופים, לא לפי השרת.
- **טלגרם מגבילה שרתי ענן** יותר ממחשבים ביתיים. אם הערוצים ריקים,
  פס המצב בראש הדף יגיד את זה במפורש — והתוכנה תתאושש לבד.
- הגרסה בענן היא **דף צפייה בלבד מבחינת המחשב** — בלי חלוניות קופצות
  (אין שולחן עבודה בענן). ההתראות נשארות בגרסת המחשב.

## 🛠 למפתחים

Go טהור, ללא תלויות חיצוניות בבילד הרגיל.

```bash
go test ./...                                        # ~80 בדיקות
go build -o tgpopup .                                # לינוקס/מק
GOOS=windows go build -ldflags "-H windowsgui" .     # ווינדוס
docker build -t tgpopup . && docker run -e PORT=10000 -e TGPOPUP_KEY=x -p 10000:10000 tgpopup
```

| משתנה סביבה | תפקיד |
|---|---|
| `PORT` | מפעיל מצב ענן: האזנה על 0.0.0.0, בלי רכיבי שולחן עבודה |
| `TGPOPUP_KEY` | מפתח גישה לדף (חובה אונליין!) |
| `TGPOPUP_CHANNELS` | רשימת ערוצים מופרדת בפסיקים, עוקפת את config.json |
| `TGPOPUP_MEDIA_HOSTS` | דומיינים נוספים שהפרוקסי של הסרטונים רשאי לגשת אליהם (ברירת מחדל: טלגרם בלבד) |
| `TGPOPUP_ADMIN_KEY` | מפתח מנהל נפרד שפותח את לוח נתוני הכניסות (רק בענן). בלעדיו הלוח מוסתר לכולם בענן |

### מה חדש ב-7.7
- **נעילת המנהל בלי צורך ב-Render**: פתיחת `.../?admin=claim` פעם אחת הופכת את המכשיר שלך למנהל (נשמר כעוגייה), והכפתור 📊 מופיע רק אצלך. בלוח יש כפתור "העתק קישור לפתיחה בטלפון" לפתיחת הנתונים גם במכשיר נוסף. (אפשר עדיין להשתמש ב-`TGPOPUP_ADMIN_KEY` למפתח קבוע שלא מתאפס.)

### מה חדש ב-7.6
- **לוח הנתונים הוא עכשיו למנהל בלבד**: בענן הוא מוסתר לגמרי מצופים רגילים, ונפתח רק עם **מפתח מנהל** נפרד (משתנה `TGPOPUP_ADMIN_KEY` ב-Render). פותחים פעם אחת `.../?admin=המפתח` וזהו. במחשב הוא תמיד גלוי (זה המחשב שלך).

### מה חדש ב-7.5
- **לוח נתוני כניסות** (כפתור 📊 בכותרת / בתפריט): מחוברים כרגע בזמן אמת, כניסות היום, סה״כ כניסות, מספר מכשירים שונים, וגרף 7 ימים. נספר בתוך התוכנה בלבד, ללא שום שירות מעקב חיצוני.
- (בענן החינמי הנתונים עשויים להתאפס בעת פריסת גרסה חדשה, כמו הארכיון והתגובות.)

### מה חדש ב-7.4
- השם שונה ל**מבזקי ארץ ישראל** בכל המקומות הגלויים.

### מה חדש ב-7.3
- **התגובות שלך נשמרות בתוך "ערוץ חי" עצמו** (בשרת), לא רק בדפדפן — אז הן מופיעות גם כשנכנסים ממכשיר אחר עם אותו מפתח. עדיין פרטיות ולא נשלחות לטלגרם.
  - בענן החינמי (Render) הדיסק מתאפס בעת פריסה מחדש, בדיוק כמו הארכיון; במחשב הן נשמרות לתמיד.

### מה חדש ב-7.2 (עיצוב)
- **מראה שקט ונקי**: פלטה רגועה בגוון אחד, טיפוגרפיה מרווחת, ואייקוני קו (SVG) במקום אמוג'י בסרגל — אחידים בכל מכשיר.
- **פס צבע דק בצד כל בועה** לפי הערוץ — זיהוי שקט בלי כותרת צועקת.
- **תגובות**: מוני האימוג'י שטלגרם מציגה על הפוסט (👍 ❤️ 🔥) נמשכים ומוצגים מתחת לבועה.
- **תגובה משלך**: לחיצה ארוכה על הודעה (או ריחוף ← ＋ במחשב) פותחת בוחר אימוג'י. הבחירה נשמרת **במכשיר בלבד** — לא נשלחת לטלגרם (אין חשבון).
- מצב בהיר אמיתי עם פלטה משלו.

### מה חדש ב-7.1
- **"מה פספסתי"** (📋): תקציר טקסטואלי של כל ההודעות מאז שקראת / היום / אתמול, ערוץ-ערוץ, בלחיצה קופצים להודעה.
- **זיכרון קריאה בין פתיחות**: קו "N הודעות חדשות" במקום שבו הפסקת, גם אחרי סגירה. המונים לא מתאפסים ברענון.
- **פתיחה מיידית**: ההודעות האחרונות נשמרות במכשיר ומוצגות מיד, עוד לפני שהשרת מתעורר. "עודכן לפני X" בכותרת.
- **סרטונים ארוכים** מסומנים מראש "זמין לצפייה רק בתוך טלגרם" — בלי כפתור ▶ מטעה ובלי ניסיונות סרק מול טלגרם.
- לחיצה ארוכה / קליק ימני על הודעה: העתק טקסט, העתק קישור, שתף, נעץ/השתק ערוץ, גודל טקסט. לחיצה ארוכה על ערוץ בנייד: נעץ/השתק.
- סינון לפי סוג (⚗️): טקסט / תמונות / סרטונים / קול. גודל טקסט ב-3 דרגות.
- **מחשב**: זיהוי "כבר רץ" לפי קוד שגיאה (עבד רק בווינדוס אנגלית — גרם לחלוניות כפולות), כתיבה אטומית של config/state, יומן קודם נשמר ב-`app.prev.log`, יציאה מסודרת מהמגש.
- **חבילות Windows נבנות אוטומטית** ב-GitHub Actions לכל דחיפה: `downloads/TelegramPopup.zip` (מלא) ו-`TelegramPopup-Update.zip` (עדכון). כפתור העדכון בתוכנה עובד שוב.

### מה חדש ב-7.0 (אונליין)

- אפליקציית טלפון (PWA): manifest, אייקון, service worker, דף "מעיר את השרת".
- התראות בדפדפן בטלפון/מחשב כשהדף ברקע.
- כניסה בטופס POST, עוגייה נגזרת (לא המפתח עצמו), Secure, הגבלת ניסיונות.
- הגנה מפני CSRF/DNS-rebinding בשרת המקומי; רשימת דומיינים לפרוקסי המדיה (SSRF).
- זרם חי שמתחבר מחדש לבד (גם אחרי שינה של השרת) ומשלים הודעות שפוספסו
  (`Last-Event-ID`, `/api/messages?since=`), בלי להוריד את כל ציר הזמן.
- שעות לפי שעון הצופה; סדר כרונולוגי נכון אחרי אתחול; חיפוש עם קפיצה להודעה.
- נייד: מוני לא-נקראו על האווטאר, כותרת בשורה אחת, תפריט ⋯, בלי זום בשדות.
- חיסכון ברוחב פס: `/api/messages` מקודד פעם אחת לכל שינוי ונדחס פעם אחת לכל ETag.

המנגנון המרכזי: קריאת הדפים הציבוריים `t.me/s/…` עם ויסות קצב עצמי —
ריווח גלובלי בין בקשות, המתנה מעריכית אחרי חסימה, וקצב שמותאם אוטומטית
למספר הערוצים. בלי זה טלגרם חוסמת, וזה מה שהפיל גרסאות מוקדמות.
